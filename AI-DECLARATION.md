# AI-use declaration

The brief allows AI coding assistants if their use is declared in writing per milestone, with tools and purpose (section 9). This file is that declaration.

## Milestone 1

**Tools**

- **Claude Code** (Anthropic's coding assistant): wrote the code, the database migrations and the tests to the developer's instructions; checked the work against the brief's acceptance criteria and the Figma frames; extracted the pixel icons and illustrations from the Figma export files with a script; drafted the README and this declaration.

- **Claude** (Anthropic's chat assistant): helped read the brief, plan the architecture and draft messages.

The developer planned the work, made the design decisions and reviewed all output before it was committed.


**Content files**

- `actions.json`, `guide.json` and `badges.json` are the files supplied by Bean Co., used unchanged. They contain no AI-written content.
- The icons and illustrations are the Figma file's own pixel sprites, exported from the frames. The six actions that have no icon in Figma show the Figma leaf icon.
